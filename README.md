# Quantum Minds Africa Initiative (QMAI)

Official website for **Quantum Minds Africa Initiative** — an educational NGO making physics, STEM, and quantum science simple, engaging, and accessible for students in underserved public schools across Nigeria.

**Live site:** [https://quantummindsafrica-org.vercel.app](https://quantummindsafrica-org.vercel.app)

> **Note:** This platform is currently an interactive demonstration preview.

## About

Founded by **Debola Oyelami** (top IGCSE Physics & Chemistry scholar in Africa), QMAI focuses on:

- Interactive school outreach programs
- Hands-on physics & chemistry experiment kits
- Simplified study materials and visual science guides
- Mentorship to nurture the next generation of African innovators

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Fonts:** Outfit + Plus Jakarta Sans (via `next/font`)
- **Deployment:** Vercel

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Project Structure

```
app/
  page.tsx          # Homepage
  layout.tsx        # Root layout + metadata
  globals.css       # Global styles
  donate/           # Donation page
  gallery/          # Photo gallery page
components/         # Reusable UI components
public/images/      # Static assets & outreach photos
```

## Features

- Responsive design with mobile-first approach
- Dedicated donation page (Naira / Providus Bank details)
- Photo gallery of real school outreach sessions
- Founder bio and impact storytelling
- FAQ section
- Newsletter signup (client-side)
